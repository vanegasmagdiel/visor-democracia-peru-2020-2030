# Closure record — phases 1–7

## Completed controls

1. **Claim and scope control:** the product is a descriptive longitudinal
   analysis with exploratory scenarios; it does not claim causal identification
   or a direct measure of state capacity.
2. **2025 anchor control:** aggregate and dimensional epistemic statuses are
   separated and machine-readable.
3. **Parameter control:** all scenario inputs are bounded, source-linked and
   attributable.
4. **Sensitivity control:** anchor, parameter, structural-scale and correlated
   residual uncertainty are propagated with a deterministic seed.
5. **Product consistency:** CSV, XLSX, app, static viewer and metadata use the
   same model outputs and status vocabulary.
6. **Licensing and provenance:** original contributions, derived data and
   third-party rights are separated.
7. **Publication control:** audited release publication is permitted;
   immutable v2.0.0 and its DOI are not overwritten.

## Subsequent controls completed

- **Phase 8:** structured multilingual search, deduplication, screening,
  full-text eligibility and a final 29-record support corpus.
- **Visual and computational QA:** figures, data workbook, static viewer and
  cross-product checks regenerated from the canonical model outputs.
- **Release independence:** journal-specific artifacts and manuscript controls
  are excluded from the software object.

## Release gate

`v2.1.0` is suitable for stable release when the clean rebuild, preflight,
Phase 8 validation, tests, secret scan, negative editorial-artifact audit and
deterministic inventory all pass. The final tag additionally requires non-RC
metadata and explicit human confirmation.
