# Release notes — v2.1.0 (2026-08-31)

## Scientific scope

- Separates the secondary-reported Peru 2025 aggregate (`5.88`) from the
  unpublished dimensional composition.
- Propagates a 10,000-member latent-anchor ensemble constrained to an exact
  mean of `5.88`.
- Documents 30 bounded scenario parameters, evidence identifiers and
  translation rules without numeric evidence weights.
- Uses common random numbers, one residual law and seed `20260825`.
- Labels p10–p90 as sensitivity envelopes rather than confidence intervals or
  event probabilities.

## Evidence traceability

- Records 767 identified and 648 screened records.
- Records 72 reports sought, 42 assessed, 13 excluded, 29 included and 30 not
  retrieved.
- Publishes record-level decisions, appraisal, a 29-record RIS export,
  evidence-integration map and 300-ppi auxiliary PRISMA figure.
- Uses PRISMA-S as an auxiliary structured-search traceability method; evidence
  rows do not change model parameters automatically.

## Reproducibility and independence

- Pins Python 3.12 and the complete dependency graph.
- Rebuilds model outputs, public data and the static viewer before release.
- Requires preflight, Phase 8 validation, 32 tests, independence/hygiene audits,
  secret scan, deterministic manifest and cross-platform pull-request CI.
- Excludes manuscripts, journal-specific files and editorial controls.
- Preserves OSF as an optional methodological complement; GitHub–Zenodo remain
  the versioned software path.
